# Flipkart Sales Dashboard 📊 | Power BI |

## 📌 Project Overview

An interactive **Flipkart Sales Dashboard** created using **Microsoft Power BI** to analyze sales performance across categories, regions, customer segments, and payment methods.

## 🎯 Objectives

* Analyze sales across different product categories
* Compare sales performance by region
* Analyze quantity sold by customer segment
* Compare payment methods
* Identify sales trends across years
* Provide interactive category filtering

## 📊 Dashboard Features

* **Quantity Sold by Segment & Region**
* **Sales by Category**
* **Sales by Category & Region**
* **Sales by Category & Payment Method**
* **Sales Trend by Category**
* **Category Slicer** for interactive filtering

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Excel/CSV Dataset
* Data Visualization
